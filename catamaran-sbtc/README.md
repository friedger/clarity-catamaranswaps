# Catamaran Swap sBTC

Catamaran Swaps allow to swap assets between Bitcoin and Stacks blockchain.

sBTC is wrapped BTC on STX.

The repo contains clarity contracts for btc-sbtc swaps.

## Contracts

btc-sbtc-swap.clar
